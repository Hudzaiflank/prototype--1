# RAB PhillyoGo: VPS, Domain, dan Operasional 1 Tahun

## Asumsi pilihan layanan

- **VPS:** Hostinger KVM 1, lokasi data center Singapura.
- Spesifikasi KVM 1: **1 vCPU, RAM 4 GB, NVMe 50 GB, bandwidth 4 TB**.
- VPS digunakan untuk backend Node.js, Socket.IO, dan database MySQL.
- **Domain:** `phillyogo.com` di Hostinger.
- Operasional mencakup update dependency, perpanjangan layanan, dan bantuan
  teknis ringan. Tidak termasuk pembuatan fitur baru.

## Catatan harga

- Harga VPS yang dipakai adalah **harga perpanjangan**, bukan harga promo tahun
  pertama. Ini membuat RAB lebih aman untuk tahun berikutnya.
- Harga Hostinger dapat berubah saat pembayaran. Harga referensi yang dicek:
  KVM 1 mulai Rp116.900/bulan untuk promo dan perpanjangan tercantum
  Rp193.900/bulan.
- Domain `.com` menggunakan harga perpanjangan Rp209.900/tahun. Harga promo
  tahun pertama dapat lebih murah dan bergantung pada periode pembayaran.
- Harga di atas belum memasukkan pajak apabila dikenakan pada checkout.
- VPS, domain, dan database menggunakan satu provider agar pengelolaannya
  sederhana. Database MySQL berjalan di VPS yang sama.

## Rincian pekerjaan operasional

Biaya **Rp500.000 per bulan** digunakan untuk:

| Kegiatan operasional | Alokasi/bulan |
|---|---:|
| Update keamanan dan dependency | Rp150.000 |
| Restart atau perbaikan ringan ketika aplikasi bermasalah | Rp150.000 |
| Pengelolaan akun, domain, dan deployment | Rp100.000 |
| Bantuan teknis dasar untuk admin/guru | Rp100.000 |
| **Total** | **Rp500.000** |

Biaya ini adalah **honor pemeliharaan ringan**, bukan biaya layanan cloud.
Jika pengelola aplikasi menangani sendiri pekerjaan tersebut, komponen
operasional dapat dihapus dari RAB.

Tidak termasuk monitoring berbayar, layanan email berbayar, backup berbayar,
pengembangan fitur baru, pekerjaan desain, dan pengadaan perangkat.
